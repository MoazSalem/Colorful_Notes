# Colorful Notes 📝

A Clean Modern and Colorful Notes App Using a Local Database with Sqflite.

Don't forget to star ⭐ the repo if you like what you see ✌️.

## Features ✨

- Material 3 Theming With Dynamic Colors
- Text and Voice Notes !!!
- Search & Edit Notes
- Arabic Support
- 3 Notes View Style
- Tablet Support
